# Como citar fontes da web

## Modelo de citação

```
[afirmação] — <fonte>, <URL>, acessado em AAAA-MM-DD.
```

Exemplo:

> A A.R.I.S. roda em Python 3.12 — python.org/downloads, https://www.python.org/downloads/,
> acessado em 2026-10-04.

Regras:

- Uma citação por afirmação de número, preço, versão ou data.
- URL completa (sem encurtador); se a página exigir login, diga isso.
- Quando a fonte secundária cita a primária, cite a primária e, se for útil,
  a secundária também.

## Checklist de confiança

| Situação | Classificação | O que fazer |
|---|---|---|
| 2+ fontes primárias concordam | confirmado | pode afirmar |
| 1 fonte primária só | provável | afirmar com "segundo X" |
| Só resumo de busca / fórum | incerto | dizer que não está confirmado |
| Fontes discordam | divergente | mostrar as duas versões |

## Cuidados

- Página de produto vende: separe especificação de marketing.
- Data de publicação antiga (< 2 anos para tecnologia) pede confirmação atual.
- PDF e página dinâmica: cite o endereço estável que você abriu.
- Resultado de busca não é fonte: a fonte é a página que abriu.
